# Praise Fellowship Church — Ely, Minnesota

Static website (HTML/CSS/JS, no framework). Content carried forward from the previous site at
[praisefellowship0.wixsite.com/praisefellowship](https://praisefellowship0.wixsite.com/praisefellowship).

- `index.html` — all sections (verse, Sundays, about/beliefs, pastor & board, church family, ministries, announcements, visit)
- `main.js` — gentle canvas light motes in the hero (pauses offscreen, respects reduced motion), reveal-on-scroll, nav
- `img/` — optimized WebP photos; credits are in the site footer
- `scripts/check-required-files.mjs` — run as the Vercel build step; fails if any referenced local file is missing
